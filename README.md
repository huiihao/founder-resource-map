# 从实验室到市场

一份给技术背景创业者的公开资源地图：创业通识、软件产品、融资、硬件制造、找代工厂、合规开公司与科技成果转化。不保证成功，只帮你少交学费。

## 在线阅读

仓库根目录的 `index.html` 是完整页面，已通过 GitHub Pages 发布：

**https://huiihao.github.io/founder-resource-map/**

也可以在本地打开 `index.html`。页面是自包含的，字体走 Google Fonts，离线时会回退到系统字体。

## 内容

| 部分 | 内容 |
| --- | --- |
| 创业通识 | YC Startup School、Stanford CS183B、MIT OCW、清华《创办新企业》 |
| 软件与产品 | YC Library、The Mom Test、Traction、定位、Indie Hackers、Product Hunt |
| 融资 | Techstars Venture Deals、YC Library、term sheet、BP 模板 |
| 硬件与制造 | awesome-hardware-production、The Hardware Startup、Seeed 白皮书、Build4Scale |
| 找代工厂 | 六步流程、审厂十问、成本量级、七个常见坑 |
| 科研背景 | 科技成果转化、职务发明、赋权、技术入股税务、离岗创业 |
| 合规与开公司 | ICP 备案、ICP/EDI 许可证、营业执照、公司 vs 个体户、上线顺序 |
| 游戏发行 | Steam 国际版首发清单、Steam 税务与分成、微信 IAA/IAP 对比与资质 |
| 资料库 | 书单、播客、社区、深圳硬件生态 |
| 行动清单 | 90 天可勾选清单，软件与硬件分支 |

## 适用对象

- 技术背景、第一次创业的人
- 做软件、硬件或软硬结合的早期团队
- 高校或科研院所出来、想把成果产品化的人
- 已经在做原型，准备找用户、工厂或融资的团队
