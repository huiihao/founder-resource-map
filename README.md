# 从实验室到量产

一份给技术背景创业者的公开资源地图：创业通识、融资条款、硬件制造、找代工厂、小批量试产，以及高校科研背景下的科技成果转化。

## 在线阅读

仓库根目录的 `index.html` 是完整页面。启用 GitHub Pages 后可以直接在线阅读：

1. 打开仓库的 **Settings → Pages**
2. Source 选择 `main` 分支，目录选 `/ (root)`
3. 保存后访问 `https://huiihao.github.io/hardware-founder-resource-map/`

不启用 Pages 也可以下载 `index.html`，双击用浏览器打开。页面是自包含的，字体走 Google Fonts，离线时会回退到系统字体。

## 内容

| 部分 | 内容 |
| --- | --- |
| 创业通识 | YC Startup School、Stanford CS183B、MIT OCW、清华《创办新企业》 |
| 融资 | Techstars Venture Deals、YC Library、term sheet、BP 模板 |
| 硬件与制造 | awesome-hardware-production、The Hardware Startup、Seeed 白皮书、Build4Scale |
| 找代工厂 | 六步流程、审厂十问、成本量级、七个常见坑 |
| 科研背景 | 科技成果转化、职务发明、赋权、技术入股税务、离岗创业 |
| 资料库 | 书单、播客、社区、深圳硬件生态 |
| 行动清单 | 90 天可勾选清单 |

## 适用对象

- 技术背景、第一次做硬件产品的创业者
- 高校或科研院所出来、想把成果产品化的人
- 已经在做样机，准备找工厂和融资的早期团队
